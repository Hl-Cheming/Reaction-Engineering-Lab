# V1.0 功能与反应工程原理

## 1. 版本范围与符号

V1.0 处理单一、不可逆、等温反应，以反应物 A 为转化率基准。连续反应器入口体积流量与空间时间为

`v_0=F_{A0}/C_{A0}`，`τ=V/v_0`。

液相恒密度时

`X=(F_{A0}-F_A)/F_{A0}=(C_{A0}-C_A)/C_{A0}`，

因而 `C_A=C_{A0}(1-X)`。

实现路径：输入、结果和任务流程在 `src/App.tsx`；物料衡算及反应器模型在 `src/core/models.ts`。

## 2. 动力学与温度修正

幂律动力学为

`-r_A=k(T)C_A^n`。

速率常数使用 Arrhenius 参考温度形式：

`k(T)=k_{ref} exp[-E/R(1/T-1/T_{ref})]`，

其中 `R=8.314462618 J·mol^{-1}·K^{-1}`。当 `T=T_{ref}` 时，`k(T)=k_{ref}`。

实现路径：`src/core/models.ts` 的速率常数、浓度和速率计算。

## 3. 液相与气相计量

液相采用恒密度关系 `C_A=C_{A0}(1-X)`。

气相采用理想气体、等温变容模型。令 `p=P/P_0`，则

`C_A=C_{A0}(1-X)p/(1+εX)`，

`v/v_0=(1+εX)/p`。

其中 `ε` 表示以 A 为基准的气相膨胀因子。模型的物理边界为 `0≤X<1`、`1+εX>0`、`p>0`。

## 4. 反应器设计方程

### 4.1 间歇反应器 BR

液相恒容：

`t=C_{A0} ∫\limits_0^X dX/(-r_A)`。

气相恒温恒压、变体积：

`t=C_{A0} ∫\limits_0^X dX/[(-r_A)(1+εX)]`。

### 4.2 全混流反应器 CSTR

一般入口转化率形式为

`V=F_{A0}(X_{out}-X_{in})/(-r_A)_{out}`。

新鲜进料 `X_{in}=0` 时，`V=F_{A0}X/(-r_A)_{out}`。釜内组成与出口组成相同，因此速率必须按出口状态计算。

### 4.3 平推流反应器 PFR

`dX/dV=(-r_A)/F_{A0}`，

`V=F_{A0} ∫\limits_0^X dX/(-r_A)`。

### 4.4 固定床反应器 PBR

速率以催化剂质量为基准时：

`dX/dW=(-r'_A)/F_{A0}`，

`W=F_{A0} ∫\limits_0^X dX/(-r'_A)`。

使用压力比 `p=P/P_0` 的简化压力降方程：

`dp/dW=-(α/2p)(F_T/F_{T0})`。

## 5. 正向与反向计算

- 已知目标转化率时，将 X 代入相应设计方程得到 `t、V` 或 `W`。
- 已知反应时间或反应器尺度时，求满足同一设计方程且位于物理区间内的出口转化率。
- PBR 考虑压降时，同时满足 `dX/dW` 与 `dp/dW`。

数值求解方法记录在 `docs/NUMERICS.md`；本文件只描述反应工程关系。

## 6. 曲线与反应器比较

结果曲线由设计方程上的状态对组成：BR 使用 `(t(X),X)`，CSTR 使用满足 `V=F_{A0}X/(-r_A)_X` 的 `(V,X)`，PFR 使用 `(V(X),X)`，PBR 使用 `(W(X),X)`。曲线不能以入口点和出口点作线性插值代替。

Levenspiel 图纵坐标为 `F_{A0}/(-r_A)`。PFR 体积等于该曲线从 0 到目标 X 的积分面积；单级 CSTR 体积等于宽度 `X_{out}-X_{in}`、高度 `F_{A0}/(-r_A)_{out}` 的矩形面积。

实现路径：曲线状态点在 `src/core/models.ts` 生成，绘制在 `src/components/LineChart.tsx`，比较界面在 `src/App.tsx`。

## 7. V1.0 边界

反应物固定为 A，不能表示多反应物、初始产物进料或惰性物质进料；限制反应物也不能由进料自动判断。这些限制在 V1.1 中解除。
