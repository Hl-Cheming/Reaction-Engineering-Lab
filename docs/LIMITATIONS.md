# 模型限制与后续扩展

## 当前限制

- 仅支持单一不可逆幂律反应；没有通用反应网络。
- 网页为等温模型；Python `energy.py` 只预留绝热接口。
- PBR 压降使用 `p=√(1−αW)` 简化式，适用于等温且总摩尔流率变化可忽略的教学情形。
- 暂不包含可逆反应的平衡常数计算、CSTR 多重稳态、内外扩散有效因子、RTD、非理想流动与参数拟合。
- 单位由界面明确标注，但当前没有任意单位制自动换算。

## 后续扩展顺序

1. 可逆反应与平衡转化率上限。
2. 联立能量衡算的绝热/换热 PFR、PBR 与 CSTR 多重稳态。
3. Thiele 模量、有效因子、Weisz–Prater 与外扩散判据。
4. RTD、串联釜模型、分散模型和非理想流动。
5. 多重反应的选择性、收率与参数拟合。
