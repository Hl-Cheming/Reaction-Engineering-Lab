# 模型限制与后续扩展

## 当前限制

- 统一反应集合支持最多 8 个组分和 8 条反应、任意带符号计量矩阵及逐反应可逆性。
- V1.6 已建立统一 `MaterialStream`（相态、温压、各组分/总摩尔流率、摩尔分率、活度和体积流量），但流程图仍限于单入口—单反应器—单出口；自由连线、分流、合流和循环尚未实现。
- PFR/PBR 支持稳态非恒温计算；BR、CSTR 仍限于恒温模型。
- 热容目前按常数处理，未包含温度相关热容、相变、辐射、径向温差和轴向导热。
- 外界温度目前沿体积恒定；尚未输入冷却剂质量流量和热容，因此不求并流/逆流冷却剂温度分布。
- PBR 压降使用含 `F_T/F_{T0}` 与 `T/T_0` 修正的简化 Ergun 形式；尚未开放由粒径、孔隙率、黏度等局部物性计算 α 的完整 Ergun 输入。
- 多反应可选择任意有入口且被消耗的物种观察转化率；分子式模式检查元素和电荷守恒，拟组分模式允许明确跳过并显示警告。
- 通用网络已经提供自适应 RK45 与隐式刚性积分；半间歇/膜进料、CSTR 多重稳态、内外扩散有效因子、RTD、非理想流动与参数拟合尚未实现。
- 单位由界面明确标注，当前输入需保持界面所示的一致单位，尚未开放任意单位制自动换算。

## 后续扩展顺序

1. 基于统一物流对象实现顺序连接的两个反应器，并加入设备间物流状态校验。
2. 非等温 CSTR 多重稳态、点火/熄火与温度相关物性。
3. 动力学数据拟合、反应机理模板与 PSSH。
4. Thiele 模量、有效因子、Weisz–Prater 与外扩散判据。
5. RTD、串联釜模型、分散模型和非理想流动。
6. 半间歇进料、膜反应器和反应器组合优化。
