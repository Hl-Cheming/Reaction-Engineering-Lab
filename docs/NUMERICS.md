# 数值方法说明

## 当前方法

- BR、PFR 和无压降 PBR：复合 Simpson 积分，固定 2000 个偶数子区间。
- 由尺度反求转化率：在物理区间 `0≤X<1` 上进行 70 次二分。
- 非恒温 PFR/PBR 及带压降气相 PBR：以 X 为独立变量，对尺度、`p=P/P0` 和 T 的适用子集使用四阶 Runge–Kutta 联立积分，并监控压力与温度失效边界。
- 通用多反应 BR/PFR/PBR：以物种状态向量为未知量，默认采用带 5(4) 阶嵌入误差估计的自适应 Dormand–Prince RK45；快慢尺度并存时可选隐式后向欧拉，并以一个整步和两个半步之差估计误差。自动模式在显式法连续拒绝步时从入口切换为隐式法。
- CSTR：按出口状态直接求解代数设计方程。

## 边界处理

- `0<X<0.999999`；
- `1+εX>0`；
- 液相浓度、气相分压、速率、尺度、热容流率和压力不得为负；
- 联立计算温度必须保持在当前物性模型的有效区间；
- PBR 在压力降模型失效前不能达到目标 X 时直接报错；
- 接近低压力边界时显示橙色或红色提示。

## 后续

单反应旧积分路径、RTD 与更完整物性模块可继续迁移到统一求解器接口；后续还需增加显式事件函数、计算取消和更完整的不收敛诊断。
