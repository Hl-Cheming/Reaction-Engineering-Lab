# 典型案例与标准答案

共同条件：一级不可逆液相反应，`k = 0.25 s⁻¹`，`C_A0 = 2 mol/L`，目标 `X = 0.8`，连续反应器入口体积流量 `v0 = 0.5 L/s`，因此 `F_A0 = 1 mol/s`。

| 模型 | 标准答案 | 解析式 |
|---|---:|---|
| BR | `t = 6.43775165 s` | `−ln(1−X)/k` |
| CSTR | `V = 8.00000000 L` | `v0 X/[k(1−X)]` |
| PFR | `V = 3.21887582 L` | `v0[−ln(1−X)]/k` |

相对误差验收限：`1×10⁻⁶`。自动化测试使用更严格的 `1×10⁻¹²` 解析比较。
