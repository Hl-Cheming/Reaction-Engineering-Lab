# 公式与模型说明

## 共同假设

当前版本以单一不可逆反应、等温理想反应器为核心。幂律动力学为 `−r_A = k C_A^n`，其中非基元反应级数 `n` 必须来自实验或题设。

Arrhenius 换算使用：

`k(T) = k_ref exp{−E/R [1/T − 1/T_ref]}`

## 化学计量

- 液相恒密度：`C_A = C_A0(1−X)`
- 气相变容：`C_A = C_A0(1−X)/(1+εX)·(P/P0)·(T0/T)`

程序强制检查 `0 ≤ X < 1`、`1+εX>0`、浓度和压力非负。

## 设计方程

- BR：`t = C_A0 ∫ dX/(−r_A)`
- CSTR：`V = F_A0(X_out−X_in)/(−r_A)_out`
- PFR：`V = F_A0 ∫ dX/(−r_A)`
- PBR：`W = F_A0 ∫ dX/(−r′_A)`
- 简化 PBR 压降：`p = √(1−αW)`

PBR 的速率必须以催化剂质量为基准。网页中的 PBR 示例把输入速率参数解释为与 `mol/(kg_cat·s)` 一致的参数，不能与体积基准速率直接互换。
