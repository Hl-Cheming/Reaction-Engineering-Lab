# 公式与模型说明（V1.6）

## 共同假设

当前界面把单一反应和多反应统一为最多 8 个组分、8 条反应的动态反应集合，不再提供平行/串联模板入口。BR/CSTR 为等温；PFR/PBR 可选择稳态等温或非恒温。

多反应不再由单一转化率重建全部组成。对每个物种使用 `R_j=Σ_mν_mj r_m` 汇总净生成速率，并分别建立 `dN_j/dt=R_jV`、`F_j0-F_j+R_jV=0`、`dF_j/dV=R_j` 或 `dF_j/dW=R'_j`。可逆步骤使用 `r_m=r_m^+(1-Q_m/K_m)`。完整推导见 `版本原理/v1.4.md`。

BR/CSTR/PFR 的 `r_m` 和 `R_j` 采用单位反应体系体积基准；PBR 的 `r'_m` 和 `R'_j` 采用单位催化剂质量基准，单位为 `mol·kg_cat⁻¹·时间⁻¹`。因此 PBR 的速率常数单位为 `mol·kg_cat⁻¹·时间⁻¹·a^{-n}`，其中 `a` 是浓度或分压，`n` 为该反应总级数。

液相幂律速率使用浓度：`r=k(T)∏_j C_j^{n_j}`；气相幂律速率使用分压：`r=k(T)∏_j P_j^{n_j}`。反应物 j 的消耗速率为 `-r_j=s_jr`。默认基元反应 `n_j=s_j`，也允许按实验值覆盖。Arrhenius 关系为

`k(T)=k_ref exp{-E/R[1/T-1/T_ref]}`。

## 组分、计量与限制反应物

- 反应物从 A 开始编号，产物继续编号，惰性物质记为 I。
- 界面以 `a、b、c、d…` 标识正计量系数；推导统一写作 `s_j`。
- 液相以 `C_{j0}/s_j`、气相以 `P_{j0}/s_j` 判定限制反应物 L；最小者为限制反应物，并列者为共同限制反应物。
- 以 L 定义 `X=(F_{L0}-F_L)/F_{L0}`，逐组分摩尔流率由反应进度 `F_{L0}X/s_L` 计算。

## 液相与气相

液相采用恒密度模型，组成直接由逐组分计量关系得到。

气相采用理想气体模型：`y_i=F_i/F_T`、`P_i=y_iP`。入口、速率和结果统一使用分压 bar，不以浓度代替。单反应总流率满足

`F_T/F_{T0}=1+εX`，

其中 `ε=y_{L0}Δs/s_L`，`Δs=Σs_products-Σs_reactants`。

## 设计、能量与压降方程

- 液相 BR：`t=C_{L0}∫_0^X dX/(-r_L)`；
- 气相 BR：`t=[P_{L0}/(RT)]∫_0^X dX/[(-r_L)(1+εX)]`；
- CSTR：`V=F_{L0}(X_out-X_in)/(-r_L)_out`；
- PFR：`dX/dV=(-r_L)/F_{L0}`；
- PBR：`dX/dW=(-r'_L)/F_{L0}`；
- PFR 能量：`dT/dV=[Ua(T_env-T)-ΔH_R(T)r]/Σ_iF_iC_{P,i}`；
- PBR 能量：`dT/dW=[(Ua/ρ_b)(T_env-T)-ΔH_R(T)r']/Σ_iF_iC_{P,i}`；
- 气相 PBR 压降：`dp/dW=-(α/2p)(F_T/F_{T0})(T/T_0)`。

反应热容和反应焓修正为

`ΔC_P=Σ_products s_iC_{P,i}-Σ_reactants s_iC_{P,i}`，

`ΔH_R(T)=ΔH_ref+ΔC_P(T-T_ref)`。

PFR/PBR 的尺度、温度和压力状态按选择条件耦合推进；完整数学推导、单位、边界和实现路径见 `版本原理/v1.2.md`。

可逆反应使用 `r_net=r_f[1-Q/K(T)]`，参考平衡常数的单位与反应商相同；`K(T)` 由含 `ΔC_P` 修正的 van't Hoff 积分得到。PFR/PBR 沿体积输出全部 `F_i`，并在适用时输出 T、`T_env`、P 和 `X_eq`。

所有多字符数学下标在界面 LaTeX 源中均成组书写，例如 `X_{\mathrm{out}}`、`T_{\mathrm{env}}` 和 `k_{\mathrm{ref}}`。
