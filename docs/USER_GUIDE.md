# 用户使用说明

## 一次计算的流程

1. 进入案例配置后，打开“组分与相态”弹窗，选择液相或理想气体，并按需添加组分、惰性标记、实际名称和分子式。
2. 点击“添加反应”，逐条选择反应物/产物、计量系数、动力学、可逆性和反应热；无需预先输入反应总数。
3. 点击 FEED 编辑入口组成、温度和流量基准；BR 中该物流表示初始装料。
4. 点击 R-101 选择或更换 BR、CSTR、PFR、PBR，并配置适用的恒温/非恒温、换热和压降边界。
5. 打开“计算规格”选择转化率基准及目标转化率或给定设备尺度；数学求解器、容差和附加选择性定义位于高级选项。
6. 核对五张摘要卡后运行计算；修改并保存条件后，旧结果会标记为失效。

“新建计算”会直接进入上述统一工作流。摘要卡显示“待完善”时，页面下方会列出最多五项具体原因且运行按钮保持禁用。被反应或计算规格引用的组分不能直接删除，按钮提示会列出应先解除的依赖。

案例在每次“保存并更新概览”后自动存入浏览器。顶部工具栏可导出带 V1.6 模式版本的 JSON、重新导入案例，或生成可另行命名/导入的副本 JSON；导入旧版扁平输入时会走统一迁移入口。

结果图中可直接点击曲线上的实际计算点，浮层会显示曲线标签（tag）及该点的 X、Y 坐标。点击没有数据点的空白区域，或聚焦图表后按 Esc，可关闭提示。可逆反应还会显示入口压力/当前进料基准下、反应温度前后各 100 K 的平衡转化率—温度曲线。

修改参数后，旧结果会标记为失效；需按新参数重新计算。

## 注意

- 计量系数的界面符号依次为 `a、b、c、d…`。
- 默认基元反应级数随对应反应物计量系数联动；手动修改级数后，如果再次修改该计量系数，级数会按新的系数重置。
- 限制反应物由进料数据判定，不固定为 A；结果中的转化率均以限制反应物 L 为基准。
- 初始产物和惰性物质不进入当前不可逆幂律速率式，但会进入出口组成；气相中还会影响总进料、稀释和膨胀因子。
- 气相速率式使用各反应物分压，输入和输出单位为 bar；不要填入气相浓度。
- U 默认 0，表示绝热；各物质热容仍用于能量衡算和反应焓温度修正，程序不会默认 `ΔC_P=0`。
- 可逆反应不能把目标转化率设在平衡转化率之上；非恒温时平衡边界会随沿程温度和压力变化。
- 转化率图的纵轴固定为 0–1；其他物理量仍按本图数据范围自动缩放。
- 多反应中的 `X_L` 表示所选观察组分 L 的净消耗比例；其他组分来自多物种联立衡算，不由 `X_L` 单独推算。若 L 被重新生成，目标搜索取第一次达到目标的位置。
- 可逆网络通常不存在唯一标量平衡转化率；每条反应分别按 `Q_m/K_m(T)` 判断方向，速率为负表示净逆向。
- 总选择性按用户指定目标/参照组分的净生成量计算；若参照组分没有正净生成量，则结果不可定义。
- PBR 的反应速率采用 `mol·kg_cat⁻¹·时间⁻¹` 的催化剂质量基准；其速率常数单位由该质量基准除以当前浓度或分压的总级数得到。BR/CSTR/PFR 则采用反应体系体积基准。
- 本工具用于教学与初步核算，不替代工程设计审查。
